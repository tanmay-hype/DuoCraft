# Gift Platform

Personalized digital gift platform built with FastAPI and Next.js.

## Architecture

- Next.js
- TypeScript
- FastAPI
- PostgreSQL
- Redis
- Docker Compose

## Requirements

Install:

- Docker
- Docker Compose
- Git

Node.js and Python are only required locally if you want to run
the services outside Docker.
